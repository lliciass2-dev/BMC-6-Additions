# Server Updates
- Server has been updated to BMC6 v7. This runs on MC 26.1.2 and NeoForge 26.1.2.116
- Download the pack [here](https://www.curseforge.com/minecraft/modpacks/better-mc-bmc6/files/all?page=1&pageSize=20&showAlphaFiles=show)
- Install the additional mods from this repository (Required mods and optional mods if you wish.)

# Mods to add Info
- Mods inside the [required mods folder](/required-mods) are required *duh* those must be downloaded to properly play on the server
- Mods in the [client-side/optional folder](/client-side-mods) are *optional* they are not required to play on the server but may enhance your minecraft experience.
- Mods in the [server folder](/server-side-mods) are only required to be installed on the server and do not have to be installed on the client.
	- If you chose to install those mods ensure that you do not add the datapack folder to your mods folder as this may break your game.
